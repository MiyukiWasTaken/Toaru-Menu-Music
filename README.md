# Toaru Series (Index/Railgun/Accelerator) Original Soundtracks as Menu Musics

This mod allows you to chose any of OSTs of the Toaru series animes EXCEPT the Miracle of Endymion movie (straight up laziness).

Every single soundtracks has been taken from Kakine Teitoku's "[A Certain Playlist](https://www.youtube.com/playlist?list=PLlURqA7x10UjN3r2HZaaLXb-cx-xmOXcN)" playlist, which contains the whole Toaru universe OSTs, huge thanks to him for listing every of those OSTs.

This mod containing ~270ish soundtracks means a big part will not really fit into the 4 (actually 5) different menus which are Main screen, Loadout screen, Heist success and Heist failure (and Credits screen bt let's be for real who will even modify it ?) because of dilution heh... I still choosed to keep the barely fitable soundtrack because maybe someone would use a track that I personally wouldn't use. 

I'm planning to adapt some soundtracks for heist music, but I'm not a sound engineer and barely have knowledge of it beside using Audacity to export a `.mp3` file to a `.ogg` ...
